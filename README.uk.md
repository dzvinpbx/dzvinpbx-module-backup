# Модуль резервного копіювання для Dzvin PBX

[![GitHub release](https://img.shields.io/github/v/release/dzvinpbx/dzvinpbx-module-backup)](https://github.com/dzvinpbx/dzvinpbx-module-backup/releases)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

**Українською** | **[English](README.md)**

Модуль створення резервних копій і відновлення Dzvin PBX: налаштування, історія розмов (CDR),
записи розмов і звукові файли. Копії можна зберігати на локальному диску, на FTP, SFTP або WebDAV.

> Це форк модуля MikoPBX **ModuleBackup** для Dzvin PBX — див. розділ [Походження](#походження).

## Можливості

- **Ручне створення копії** з вибором вмісту: налаштування PBX, історія розмов, записи розмов, звукові файли
- **Архівація за розкладом** з обмеженням кількості збережених версій
- **Зовнішні сховища** — FTP, SFTP, WebDAV
- **Відновлення** з ZIP або IMG-копії, а також із вивантаження налаштувань зі старої Askozia PBX (XML)
- **Веб-інтерфейс** — список копій, завантаження, видалення, прогрес виконання
- **REST API** — `/pbxcore/api/modules/ModuleBackup/` (`list`, `start`, `stop`, `download`, `recover` та ін.)

## Вимоги

- Dzvin PBX версії 2024.1.114 або вище

## Встановлення

1. Перейдіть у **Модулі** → **Маркетплейс** на панелі адміністрування Dzvin PBX
2. Знайдіть модуль **Резервне копіювання**
3. Натисніть **Встановити**

Або з релізу GitHub: завантажте `.zip`, потім **Модулі** → **Встановлення модуля**.

## Використання

- **Резервне копіювання** — оберіть, що архівувати, і запустіть створення копії.
- **Розклад архівації** — увімкніть архівацію за розкладом, вкажіть час, кількість версій і, за потреби, віддалене сховище.
- **Відновлення з архіву** — завантажте файл копії й оберіть, що відновити. Відновлення налаштувань необоротне,
  станція автоматично перезавантажується.
